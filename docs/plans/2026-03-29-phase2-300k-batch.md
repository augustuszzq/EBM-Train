# Phase 2 300k Batch Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add Phase 2 300k manifest, submission, local-eval, and summary plumbing by reusing the existing Phase 1 ablation infrastructure.

**Architecture:** Keep `pbs_run_ablation_case.pbs` and `run_eval_ablation_case.sh` as the only train/eval runtimes. Extend the Phase 1 submitter and collector with a few new parameters, then add thin Phase 2 wrappers and a dedicated Phase 2 manifest/report renderer. This avoids a second launcher path and keeps Phase 2 aligned with the already-debugged canonical runners.

**Tech Stack:** Bash wrappers, Python CSV/JSON tooling, existing PBS launcher scripts, pytest.
