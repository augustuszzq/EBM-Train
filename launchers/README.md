# Launchers Layout

- `launchers/current/`
  - Current multinode launchers used by the active workflow.
- `launchers/archive/`
  - Old SSH-based or superseded launchers kept only for reference.

Current canonical launchers:

- `launchers/current/run_hsn.sh`
- `launchers/current/run_hsn_baseline.sh`
- `launchers/current/run_hsn_pipeline.sh`
